# Pi Extensions

Private monorepo for Hugo's custom Pi extensions.

## Layout

Each extension lives in `packages/<name>/` and keeps its own manifest, README, source and tests. The root uses pnpm workspaces.

## Migration

No extension has been imported yet. Existing repositories and local Pi extensions remain unchanged. Review each extension's license, dependencies and installation path before importing it. Preserve upstream attribution and record the source revision for each import.

Do not commit credentials, environment files, session journals or local agent settings. This repository is private; making it public requires separate approval.
